# Mock Backend Learning Project

## Project Idea (Phase 1 Only)
**Smart Subscription Billing & Entitlement Platform**

A backend system for businesses that sell subscription plans (e.g., SaaS or online learning platforms). The system must handle entitlement rules, billing cycles, upgrade/downgrade flows, pause/cancel states, and proration logic. It is designed as a **modular monolith** with real business logic beyond simple CRUD.

This repo captures the initial concept and will be expanded in later phases.
